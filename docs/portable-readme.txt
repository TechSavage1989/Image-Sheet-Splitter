IMAGE SHEET SPLITTER
====================

Run "Image Sheet Splitter.exe" directly. No installation is required.

Main workflow
-------------
1. Add image sheets with Add Image(s), Add Folder, or drag and drop.
2. Choose the output directory.
3. Adjust separator detection only if needed.
4. Click Split Images.

The app supports PNG, JPEG/JPG, BMP, and WebP source images. Exported pieces are PNG files.

Settings, logs, update cache, downloaded updates, staging files, and rollback data are stored under the current user's application-data folder by default, not beside the EXE.

Updates
-------
The app checks the public GitHub release feed at startup, every five minutes while active, and after returning to the app when enough time has passed. Downloads and restarts are never automatic.

Use Help > Check for Updates for a manual check. When an update is available, choose Download, then Install and restart when you are ready.
