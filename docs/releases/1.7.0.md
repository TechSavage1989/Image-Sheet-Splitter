# Image Sheet Splitter 1.7.0

## What's new

- Renamed the application from Sprite Sheet Splitter to Image Sheet Splitter while preserving the existing splitter workflow.
- Added a stable Windows portable executable name: Image Sheet Splitter.exe.
- Added a token-free GitHub Releases updater with startup, five-minute, and focus-return checks.
- Added explicit Download and Install and restart actions with SHA-256, archive-safety, PE identity, version, rollback, and post-relaunch health validation.
- Moved default application state to per-user ImageSheetSplitter application-data folders with migration support for the prior SpriteSheetSplitter configuration.
- Reorganized source, tests, assets, documentation, build scripts, and CI around a compact repository root.
- Added repository-root allowlist enforcement and a negative-control test.
- Fixed update launch quoting for paths with spaces, protected existing executables on destination collisions, and bound health confirmation to the expected version, process, executable, and update attempt.
- Added native Windows replacement and rollback tests with preserved settings and shortcuts, plus compiled icon and release checksum validation.

## Notes

This is the first Image Sheet Splitter release candidate. Upgrade testing uses a synthetic 1.6.0 fixture because there is no earlier published Image Sheet Splitter release. Native tests also replace that fixture with the compiled 1.7.0 app and exercise failed-health rollback. Download and restart always require an explicit action in the app.
