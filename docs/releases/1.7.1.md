# Image Sheet Splitter 1.7.1

## What's new

- Shows the installed version beside the application title, making successful updates easy to confirm.
- Improves Windows rollback reliability by waiting for released executable file locks before restoring the previous build.
- Strengthens the native updater tests for the PyInstaller parent/child process lifecycle.

## Notes

This small update is intended to test the built-in updater from v1.7.0. Existing splitting, drag-and-drop, settings, logging, descriptive/generic output naming, icon, and stable executable filename are unchanged.

Updates still require an explicit Download and Install and restart. The first real version-to-version updater test must be completed on Windows before the process is considered verified.
